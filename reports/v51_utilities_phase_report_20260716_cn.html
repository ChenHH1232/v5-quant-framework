一、阶段结论

项目经理结论：V5.1 到目前为止可以视为“流程复制验证阶段完成”。它证明 V5 的研究流程可以从银行板块迁移到公用事业板块，并且本地模拟聚宽与聚宽冻结信号测试可以高度对齐。但 V5.1f 仍不是正式接受策略。

V5.1 的核心价值不在于一次回测收益很高，而在于验证了 V5 的组织方式：Research Agent 先提出行业逻辑，Quant Validation Agent 做统计验证，Engineering Agent 做平台复刻与风险审计，Project Manager Agent 负责分层拦截。

  • 最终候选模型 V5.1f 使用电力需求状态切换因子：弱需求偏高股息，中性需求偏经营现金流收益率，强需求偏低 PB。

  • 聚宽阶段使用冻结信号脚本，验证平台执行与本地 runner 是否一致。

五、相比 V4 的提升

流程提升

V4 更像单策略迭代；V5 形成了 Research、Quant、Engineering、PM 的分工与互相制衡。

数据口径

V5 强制区分 PIT 研究、平台复刻、工程 smoke test、paper trading，避免不同目的测试混用。

平台复刻

本地 runner 已能复刻聚宽冻结信号结果，显著减少反复去聚宽消耗积分和时间。

风险门禁

新增过拟合审计：幸存者偏差、未来函数、样本污染、随机区间和执行时点扰动不再靠人工记忆检查。

六、仍需警惕的问题

  • V5.1f 的历史收益过高，必须首先当作“需要解释的现象”，不能当作策略已成立。
  • 聚宽当前通过冻结信号执行测试，不代表 live-factor recomputation 已经完全打通。
  • 公用事业模型依赖外部电力需求状态，后续需要持续维护数据源和可见日期规则。
  • 2021-2026 只应作为平台复刻/模拟聚宽窗口，不应继续被用于调参或接受策略。
  • 正式接受前必须进入 paper trading，记录未来每次调仓信号、状态判断、持仓和实际表现。
