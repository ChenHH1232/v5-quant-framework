# V5 Naming Policy

Date: 2026-07-21

## Rule

`V5` is the project name. Do not create new main-version labels for workflow branches.

Use branch/module labels under V5:

- `V5a.1`
- `V5a.2`
- `V5b.1`
- `V5b.2`

## Current Meaning

- `V5a.1`: broad-sector coarse screening for the dividend low-volatility / operating-cash-flow / sector-approved FCF enhanced ETF path.

## File Naming

File paths may use `v5a.1_...` when the filesystem and tools support it. If a tool has trouble with dots in path names, use `v5a1_...` in the file path and keep `V5a.1` in the project metadata and reports.

## PM Rule

Version labels are governance labels, not performance labels. A strategy or sleeve cannot be promoted because a new version label exists.
