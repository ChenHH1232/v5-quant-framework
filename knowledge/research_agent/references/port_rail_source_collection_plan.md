# Port / Rail Source Collection Plan

Date: 2026-07-18

Owner:

```text
Research Agent
```

## Source Priority

1. Annual reports and interim reports for company-level operating disclosure.
2. Exchange announcements and official company operation announcements.
3. Official port / railway / transport statistics where available.
4. JoinQuant / DataJQ financial and valuation data for PIT factor construction.
5. Brokerage research and investor articles only as hypothesis material.

## Manual Review Targets

For each selected company, collect:

```text
report_period
publish_date
visible_date
port_or_rail_revenue_share
cargo_throughput_or_freight_volume
tariff_or_pricing_policy
capex_project_commitment
source_title
source_url
original_announcement_checked
review_status
```

## Anti-Crawling Rule

Do not force crawl websites that block automation.

If a source blocks automation, create a manual import template and record the source route.
